アドバンスサークル（以下「当事業」）は、お申込み・お問い合わせ等を通じて取得する個人情報を、個人情報の保護に関する法律その他の関係法令を遵守し、適切に取り扱います。

1. 事業者の情報

  • 名称：アドバンスサークル（赤塚 裕人の個人事業）
  • 住所：ご請求があった場合に、遅滞なくお知らせします。

2. 取得する個人情報

お申込み、お問い合わせ、セッション等を通じて、お名前、メールアドレス、電話番号、お申込み・ご相談の内容など、ご本人からご提供いただいた情報を取得します。

3. 利用目的

  • お申込み・お問い合わせへの対応、およびそのための連絡
  • コーチング・セミナー等のサービスの提供
  • サービスやイベントのご案内（メールマガジンを含みます）

取得した個人情報は、上記の目的の範囲内でのみ利用します。

4. 第三者への提供

法令に基づく場合を除き、ご本人の同意なく個人データを第三者に提供しません。

なお、次条の業務の委託に伴って個人データを提供する場合、当該委託先は個人情報の保護に関する法律第27条第5項第1号により「第三者」に該当しません。ただし外国にある委託先については、同法第28条の定めに従い、第6条のとおりご本人の同意をいただいたうえで提供します。

5. 業務の委託と、委託先の所在地

当事業は、お申込み・お問い合わせ等のフォームの運用、メールの送受信、記録の保管に、Google Workspace（Google フォーム、Gmail 等）を利用しています。当事業が Google Workspace について契約している事業者は、次のとおりです。

  • 事業者名：Google Asia Pacific Pte. Ltd.
  • 所在する外国：シンガポール共和国

当事業は、この委託先に対し、個人情報の保護に関する法律第25条に基づく必要かつ適切な監督を行います。委託先における取扱いは、当事業が委託した業務の範囲に限られます。

6. 外国にある第三者への提供について

前条のとおり、当事業の委託先は外国（シンガポール共和国）にあります。そのため当事業は、フォームから個人情報をご提供いただく際に、外国にある第三者への個人データの提供を認める旨のご本人の同意をいただいています。同意をいただく前提として、個人情報の保護に関する法律第28条第2項および同法施行規則第17条第2項に基づき、以下の情報を提供します。

  • (1) 当該外国の名称：シンガポール共和国
  • (2) 当該外国における個人情報の保護に関する制度に関する情報：シンガポール共和国には個人情報の保護に関する制度として個人データ保護法（Personal Data Protection Act 2012）があり、監督機関として個人データ保護委員会（Personal Data Protection Commission）が置かれています。詳細は、個人情報保護委員会が公表する調査結果「シンガポール共和国における個人情報の保護に関する制度等の調査」（PDF）をご参照ください。
  • (3) 当該第三者が講ずる個人情報の保護のための措置に関する情報：委託先は、当事業との間の Cloud Data Processing Addendum に基づき、当事業の指示の範囲内でのみ個人データを取り扱うこと、従業者に守秘義務を課すこと、技術的・組織的な安全管理措置を講じること、再委託先を公表し当事業に事前に通知すること、および情報セキュリティに関する第三者認証（ISO/IEC 27001、SOC 2／SOC 3 等）を維持することを定めています。再委託先の名称・所在国は、委託先がGoogle Workspace の再委託先一覧として公表しています。

同意をいただけない場合、フォームからのお申込み・お問い合わせをお受けすることができません。

7. 保有個人データの安全管理のために講じた措置

  • 基本方針の策定：本方針を策定し、本ページで公表しています。
  • 組織的安全管理措置：個人データを取り扱う者を、事業主（赤塚 裕人）に限定しています。
  • 技術的安全管理措置：個人データを取り扱う情報システムへのアクセスに、アカウント認証および多要素認証を用いています。
  • 外的環境の把握：当事業は、第5条のとおりシンガポール共和国に所在する事業者に個人データの取扱いを委託しており、外国において個人データを取り扱うこととなります。同国の個人情報の保護に関する制度については、個人情報保護委員会が公表する調査結果（シンガポール共和国）により把握したうえで、第6条(3)に記載の措置が委託先において講じられていることを確認し、委託先の監督を行っています。

個人データが保存されるサーバが所在する国について：当事業は、当事業の個人データが保存されるサーバが所在する国を特定できません。その理由は、委託先との契約（Cloud Data Processing Addendum）において、データは委託先またはその再委託先が設備を有するいずれの国においても取り扱われ得ると定められており、個々のデータの保存先が当事業に開示されないためです。ご本人の参考となる情報として、委託先は再委託先の名称・所在国をGoogle Workspace の再委託先一覧として公表しています。
